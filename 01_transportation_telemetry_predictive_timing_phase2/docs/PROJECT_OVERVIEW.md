# Transportation Telemetry Predictive Timing Platform

## Project Question

**Can a real-time transportation telemetry platform predict train delay timing and support predictive maintenance decision-making using sensor, location, and operational event data?**

This project is inspired by railway predictive maintenance research and a Sr/Staff Data Engineer transportation platform role.

The package demonstrates:

- synthetic train telemetry event generation
- Bronze / Silver / Gold lakehouse-style data pipeline
- data quality, deduplication, and certified feature tables
- neural network model for delay risk and delay-minute prediction
- evaluation tables and visual outputs
- Streamlit dashboard
