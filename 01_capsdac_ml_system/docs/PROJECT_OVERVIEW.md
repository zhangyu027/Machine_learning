# CAPSDAC ML System Project Overview

## Project Question

**Can monthly CAPSDAC child enrollment snapshots be used to forecast near-term CSPP enrollment and identify the county, site, and vendor drivers of future demand?**

## Business Context

The California State Preschool Program planning workflow depends on understanding how enrollment changes across time, sites, counties, and vendors. This project builds a data science workflow to:

- create monthly child enrollment snapshots
- forecast 3-5 months of near-term enrollment
- identify top contributing sites
- identify top contributing counties
- identify top contributing vendors/LEAs
- visualize geographic and site-level concentration of enrollment
- support program planning and resource allocation

## Portfolio Framing

This is a practical public-sector education analytics project. It combines:

- data engineering
- time-series forecasting
- contribution analysis
- geospatial visualization
- stakeholder-facing reporting
- reproducible notebooks

## Key Outputs

The package includes:

- historical and predicted enrollment trend chart
- county-level enrollment contribution heat map
- top 20 site monthly contribution heat map
- top site contribution bar chart
- top vendor contribution bar chart
- top forecasted sites
- top forecasted vendors
- site and LEA enrollment growth charts

## Important Note

This project supports planning and monitoring. Forecasts should be reviewed with program context and should not be treated as final administrative counts.
