# Interview Narrative

I designed a Databricks-style clinical NLP lakehouse pipeline. The project starts with synthetic healthcare notes, applies Spark-compatible preprocessing, creates a standardized Silver NLP table, trains a baseline TF-IDF model, produces evaluation artifacts, and exposes an inference API.

For a Data Engineer role, the most important design elements are the layered data architecture, reproducible pipeline execution, validation artifacts, and clear separation between raw data, curated features, model outputs, and API serving.
