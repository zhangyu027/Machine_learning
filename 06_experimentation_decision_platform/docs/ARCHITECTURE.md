# Architecture

## Local executable flow

```text
Synthetic experiment event CSV
        ↓
Schema and input validation
        ↓
Frequentist A/B estimates + CUPED
        ↓
Bayesian conversion decisioning
        ↓
T-Learner heterogeneous effects
        ↓
Thompson Sampling simulation
        ↓
Versionable reports, scores, and model artifacts
```

## Service layer

The FastAPI service exposes health, Prometheus metrics, and an authenticated Bayesian conversion-analysis endpoint. The API is stateless; batch artifacts remain generated by the pipeline.

## Enterprise extension path

In production, event data would arrive through a governed warehouse or streaming platform, experiment assignment would be immutable and auditable, metric definitions would live in a semantic layer, orchestration would use a scheduler, and results would be persisted to a decision registry. The included repository demonstrates these boundaries but does not claim a deployed enterprise control plane.
