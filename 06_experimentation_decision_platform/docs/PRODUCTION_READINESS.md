# Production Readiness

## Validated capabilities

- Import-safe package layout
- Direct script and module execution
- Frequentist, CUPED, Bayesian, uplift, and bandit components
- FastAPI request and response contracts
- API-key protection without a default credential
- Automated unit, integration, and API tests
- Docker and GitHub Actions scaffolding

## Remaining limitations

- Synthetic data only
- Local CSV and filesystem artifact persistence
- No production experiment assignment service or metric catalog
- No distributed compute or warehouse integration
- T-Learner is a reference baseline, not a validated causal production model
- Bayesian thresholds are illustrative business rules
- No online bandit traffic allocation
