# Interview Narrative

This project demonstrates a data-engineering-first approach to medical imaging AI. Rather than focusing only on model training, it shows how imaging metadata and clinical attributes can be organized into Bronze, Silver, and Gold layers, validated locally, and connected to model evaluation artifacts.

## Principal Data Engineer Positioning

- Built a reproducible clinical AI lakehouse pipeline.
- Standardized imaging metadata and clinical features.
- Created Gold feature tables for model validation.
- Persisted evaluation summaries for governance and auditability.
- Preserved a notebook-based imaging AI extension for experimentation.
