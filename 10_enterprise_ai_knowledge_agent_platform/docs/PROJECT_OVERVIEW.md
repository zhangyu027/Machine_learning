# Enterprise AI Knowledge Agent Platform

## Project Question

**Can a private enterprise AI agent platform answer questions across documents, SQL tables, and image notes with citations, confidence scoring, and hallucination checks?**

## Why this fits Yu Zhang's portfolio

This package connects directly to experience in healthcare AI, education/public-sector analytics, data governance, de-identification, RAG systems, transportation telemetry, Python, SQL, and stakeholder-facing analytics.

## What this project demonstrates

- local/private LLM deployment with Ollama
- local embeddings with sentence-transformers
- FAISS vector search
- PDF/text ingestion
- image-note ingestion support
- SQL agent over local CSV/SQLite-style data
- tool orchestration
- multi-agent workflow
- citation-grounded answers
- citation confidence scoring
- hallucination risk detection
- benchmark evaluation
- Streamlit app
- Jupyter notebook
