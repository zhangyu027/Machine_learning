# 02 Medical Imaging Clinical AI Lakehouse Pipeline

**Principal Data Engineer Edition**

This project demonstrates how a Data Engineer can structure a medical imaging AI workflow as a healthcare lakehouse pipeline. It converts synthetic imaging metadata and clinical attributes into Bronze, Silver, and Gold datasets, then trains a lightweight baseline model to validate the end-to-end pipeline.

## What This Demonstrates

- Medical imaging metadata ingestion
- Bronze / Silver / Gold lakehouse data modeling
- Clinical feature engineering for imaging AI
- Local runnable pipeline for portfolio validation
- Evaluation artifacts and governance-ready summaries
- Streamlit viewer for clinical AI outputs
- Optional notebook-based deep learning extension using MedMNIST

## Local Demo

From the project root:

```bash
pip install -r requirements.txt
python scripts/run_pipeline.py
pytest -q
```

```text

```

## Data Engineering Narrative

This project is positioned as a medical imaging data platform rather than only a model notebook. The pipeline ingests imaging study metadata and clinical attributes, standardizes fields in the Silver layer, produces a Gold patient-imaging feature table, and creates evaluation artifacts for reproducibility and governance.

## Interview Narrative

“I designed a medical imaging clinical AI lakehouse pipeline that organizes imaging metadata and clinical attributes into Bronze, Silver, and Gold layers. The project demonstrates ingestion, feature engineering, data quality checks, model evaluation artifacts, and a review app. The goal is to show how clinical AI systems require reliable data engineering foundations before model deployment.”

## Production Positioning

In production, the Bronze layer would land DICOM/image metadata and clinical source extracts from secure systems. Silver would standardize PHI-safe metadata, imaging labels, and clinical attributes. Gold would expose governed feature tables for ML training, validation, monitoring, and clinical review workflows.

## Important Clinical Limitation

This is a portfolio and education project. It is decision support, not diagnosis. The local pipeline uses synthetic demo data, and the optional MedMNIST notebook uses public benchmark data.
