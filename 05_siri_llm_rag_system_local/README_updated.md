# Personal AI Assistant RAG System

## Production-Oriented Local Retrieval-Augmented Generation (RAG) Platform

This project demonstrates a modern local RAG application using Ollama, FAISS, sentence-transformers, FastAPI, and Streamlit.

### Highlights
- Local-first RAG
- FAISS vector search
- Ollama local inference
- Streamlit UI
- FastAPI API
- Retrieval evaluation
- Privacy-first architecture
- Production-oriented engineering
