# Governance and Privacy

This package uses synthetic healthcare/public-sector style data.

## Public GitHub Safety Rules

Do not commit:

- raw PII
- names
- birth dates
- addresses
- student or patient identifiers
- secure warehouse paths
- credentials
- internal production extracts

## Recommended production governance

- role-based access control
- de-identification
- schema validation
- table lineage
- certified dataset ownership
- audit logs
- model monitoring
- MLflow model registry
- data quality SLA checks
