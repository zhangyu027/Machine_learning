# AI Data Platform / Lakehouse Project

## Project Question

**Can a modern healthcare/public-sector lakehouse improve scalable AI analytics and forecasting workflows?**

## Why this fits the portfolio

This project is designed for Yu Zhang's background in:

- CAPSDAC-style public-sector analytics
- Spark/Hadoop-style scalable data engineering
- forecasting workflows
- education and healthcare analytics
- data governance and de-identification
- operational dashboards
- ML-ready certified datasets

## What this project demonstrates

- Bronze / Silver / Gold lakehouse layers
- local Delta-style parquet tables
- streaming ingestion simulator
- dbt-style SQL transformation models
- Airflow-style orchestration DAG
- feature store table
- MLflow-ready forecasting model
- governance layer and data quality checks
- Streamlit dashboard
- notebook demo
- step-by-step reproducible pipeline
